# Leaf 猫猫：角色与使用规范

## 角色基准

Leaf 猫猫是一只不戴眼镜的黑猫，采用宽脸、偏长的三角耳、简洁米白椭圆眼睛、小身体、圆爪和弯尾巴。角色母版为 `assets/mascot/leaf-cat-master.png`。

性格安静、好奇、认真。它陪伴阅读，空状态中引导下一步，不表现责备或沮丧。整套角色都不戴眼镜，包括睡觉时的额头；也不添加帽子、腮红或闪亮大眼睛。

## 固定识别特征

- 黑色主体，耳尖微圆，不增加毛束或花纹。
- 米白椭圆眼白、深色椭圆瞳孔、小米白鼻子；不为眼睛添加彩色外圈。
- 每侧三根简洁胡须，圆爪、短脚、平滑弯尾。
- 动作通过视线、头部倾斜、爪子与尾巴表达，保持头身比例一致。
- 每幅只有一只猫与一组主要道具，不在插画内添加文字。
- 保留原始插画的配色与细节，深浅色模式共用同一张图片。

## 色彩与深浅色

正式素材直接使用 `assets/mascot/sources/` 中的无眼镜原始插画，保留原始尺寸、颜色和透明度。

Dark / Light 共用同一张 PNG。渲染不添加抖动算法、像素化、描边、反色、亮度滤镜或圆形底托，图片按固定容器正常缩放。应用强调色保持 `#445A51`。

## 场景与接入

| 文件                 | 场景             | 界面行为                                               |
| -------------------- | ---------------- | ------------------------------------------------------ |
| welcome-sleeping.png | 枕书睡觉         | 尚无阅读记录的书架欢迎区；开始阅读后让位于继续阅读     |
| reading.png          | 安静捧书         | 可复用的阅读辅助姿态                                   |
| empty-library.png    | 扶书招手         | 真实空书库，提供导入 PDF 操作                          |
| empty-search.png     | 翻书寻找         | 清空搜索或修改关键词；文档搜索完成后才显示             |
| empty-favorites.png  | 抱着喜欢的书     | 收藏为空，引导点击书籍爱心                             |
| empty-collection.png | 把书放进书盒     | 分类为空，提供前往书架选书的入口                       |
| settings.png         | 整理书签         | 阅读偏好中的小装饰，设置项是主体                       |
| empty-bookmarks.png  | 捧着书签         | 书签侧栏为空，引导添加当前页书签                       |
| empty-notes.png      | 准备写笔记       | 高亮、划线和笔记为空，引导选中文字                     |
| empty-tags.png       | 拨弄纸标签       | 标签空状态组件预留，当前不新增标签管理功能             |
| empty-outline.png    | 侧头翻页         | 目录读取完成且无目录，提供缩略图入口                   |
| not-found.png        | 坐在书旁歪头寻找 | 无效应用页面，返回书架；有应用内上一页时显示返回上一页 |

页面级空状态约 184px；侧栏约 104px；设置装饰 72px；欢迎横向构图 184–240px。固定尺寸和 `object-fit: contain` 避免图片加载推移布局。装饰图片使用空 alt，含义由旁边的标题和说明表达。

`src/components/Mascot.tsx` 统一提供 `Mascot`、`EmptyState`、`Welcome`、`SettingsIllustration`、`NotFound`。图片位于 `public/mascot/`，清单为 `public/mascot/manifest.json`。`EmptyState scene="tags"` 可供后续标签功能使用。

404 只处理无效应用地址。PDF 文件丢失、密码错误、损坏或页码无效应继续显示具体问题和对应操作。

## 交付与重新处理

完整互动预览为 `leaf-scenes.html`，支持深浅色切换和逐张下载。12 个姿态各有一张 PNG，两种主题共用。原始插画保存在 `assets/mascot/sources/`，不进入应用包。

运行 `node scripts/build-mascots.mjs` 将原图原样复制到 `public/mascot/`，并更新素材尺寸清单。
