# Leaf 青蛙：Icon 与 IP 视觉提案

为本地 PDF / Markdown 阅读器设计一个安静、亲切且精致的阅读伙伴。参考用户提供的角色图标集合，采用大色块、近距离裁切、简单五官与轻微立体感。主角是原创灰绿青蛙。

## 统一识别

宽圆的脸与两个圆形眼部隆起构成主轮廓，米白眼白、深色椭圆瞳孔和短弧线微笑构成五官。无鼻子、服装、眼镜、花纹或多余装饰。颜色与光影保持低饱和、低光泽。

Icon 使用微微倾斜的脸部近景，深绿底板保持清晰对比。IP 使用同一套五官与头部形状，延展出小身体、圆手和宽脚，捧书表达陪读角色。图标不叠加书本，使 24–48 px 时五官有足够空间。

## 色彩目标

| 用途 | 色值 |
| --- | --- |
| 青蛙主体 | `#8FA88B` |
| 眼白、书页、腹部 | `#F5F1DF` |
| 书封与界面深绿 | `#445A51` |
| Icon 深绿底板 | `#344D43` |
| 五官 | `#26322C` |

生成图像包含自然明暗变化，色值是设计目标，不能作为图片中每个像素的精确承诺。

## 交付

- `icon-source.png`：不透明、满版的 Icon 原画，可供不同平台重新制作图标。
- `icon.png`：1024 × 1024 PNG，896 px 圆角底板，四周 64 px 透明安全区。
- `character.png`：透明背景的捧书 IP 母版。
- `index.html`：深浅色、小尺寸与界面场景预览，附素材下载。
- `preview-light.png` / `preview-dark.png`：预览页静态图。
- `prompts.json`：使用内置 image_gen 的完整设计提示词。

Icon 的圆角与透明安全区由 `export-icon.mjs` 按确定尺寸导出，可运行 `node docs/design/modern-identity/export-icon.mjs` 重新生成。IP 保留生成器输出的透明度与原始尺寸。

当前交付为完整视觉提案，正式应用图标与现有角色场景尚未切换。角色用于欢迎区和空状态；阅读正文中避免持续出现大尺寸装饰。深浅主题共用同一角色素材，不使用反色或着色滤镜。
